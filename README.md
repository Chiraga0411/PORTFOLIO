# Chirag Agarwal – Portfolio (React + Tailwind)

1. Copy your old `assets/` folder contents into `public/assets/`
   (needs: `Gemini_Generated_Image_6vr02n6vr02n6vr0.png`, `mail.png`,
   `icons8-github-30.png`, `linkedin.png`).
2. `npm install`
3. `npm run dev`  → local dev server
4. `npm run build` → production build in `dist/`

All text (projects, skills, experience, links) is in `src/data.js`.
